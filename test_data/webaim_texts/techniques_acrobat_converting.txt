Overview
A great deal of effort is often devoted to remediating PDF files with accessibility issues. Most of this work can be avoided by choosing a source document that supports conversion to an accessible PDF. This article focuses on Microsoft Office 365 source documents exported to PDF using Acrobat.

Recreate the source document
When a PDF is untagged, or has an incomplete or incorrect tag structure, it is often best to return to the source document, make the necessary accessibility repairs, and then re-create the PDF. If the source document is unavailable, use Acrobat to convert a PDF back to a Word, PowerPoint, or Excel file to create a new source document. Select
